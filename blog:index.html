2024-10-30 Cryptography CTF
Breaking Weak RSA: Small Exponent and Common Modulus Attacks

An implementation-level look at classical RSA vulnerabilities. I cover Wiener's continued fraction attack against small private exponents, the broadcast attack (Håstad's theorem) when the same message is encrypted to multiple recipients, the common modulus attack, and Franklin-Reiter related message attacks — all with working Python PoC code using SageMath and pycryptodome.
