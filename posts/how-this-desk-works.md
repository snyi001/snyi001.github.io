# 这张桌子是怎么回事

你现在看到的这个页面，是一间用代码画出来的房间。桌上留了五样东西，都是我自己选的。

## 桌上有什么

- **笔记本**——就是这篇博客。文章是 `posts/` 里的 .md 文件，我 push 上去，这里就多一篇
- **猫**——白色的波斯猫，会跟着你的指针，点它会醒
- **唱片机**——可以点开放一首歌
- **咖啡**——会一杯一杯变少
- **台灯**——按深圳的日落自己亮，也可以手动开关

## 为什么删掉别的东西

原本这张桌子上还有平板、手机、打印机、植物、日记本、游戏机。它们能演示的东西很多，但**跟我没关系的东西，摆在那只是噪音**。

留下的五样，都能回答一个问题：**我是谁**。

## 怎么加文章

在这个仓库的 `posts/` 目录里放一个 `.md` 文件就行：

```markdown
---
title: 标题
date: 2026-11-20
summary: 一句话摘要
---

正文随便写。
```

文件头那几行会被读成标题、日期、摘要、分区和标签；下面是正文，支持标题、列表、引用、代码、链接和图片。

> 不用动一行代码，push 完刷新就能看到。

## 分区和标签

文件头里写 `category` 就会自动多一个分区，写 `tags` 多两个标签：

```markdown
---
title: 一道 CTF：从栈溢出到拿到 shell
date: 2026-07-02
summary: 一句话摘要
category: 网安
tags: CTF, pwn
---
```

现在的分区是：**网安**（标签 CVE / CTF）、**AI小笔记**、**IO小笔记**、**随笔**。想加新分区，直接写一个新名字就行。

## 文章里放图片

两种写法，图片文件放在 `posts/` 目录里（比如 `posts/images/`）：

```markdown
![图的说明](images/stack-overflow.svg)
```

单独一行写，会变成带图注的图；混在文字里写，就是一张行内的图。

图片路径是相对 `posts/` 的，所以 `images/a.png` 指向 `posts/images/a.png`。支持 png / jpg / webp / svg / gif。

## 也可以直接上传 Word

不想写 Markdown 的话，把 **.docx 直接放进 `posts/`** 就行，浏览器会自己把它读出来（不用转换、不用插件）。

- 标题：文档里的「标题 1」会变成文章标题；没有就用文件名
- 保留：段落、**粗体**、*斜体*、项目符号、编号、表格、图片
- 不保留：字体、字号、颜色、缩进、页眉页脚——只留结构，样式统一由博客决定
- 文件名可以带信息：`[网安] 2026-11-09 我的标题.docx` → 分区「网安」、日期 2026-11-09、标题「我的标题」
- 只想先看看效果：把文件**直接拖到博客页面上**，会立刻渲染出来（顶部会写「本地预览」）；要真的出现，还是得放进 `posts/` 并上传
