// methodology

Think Like an Attacker,
Build Like a Defender

Every vulnerability starts with curiosity. My approach is to deeply understand systems at the lowest level — assembly, memory layout, cryptographic primitives — before attempting to break or secure them.

From static binary analysis to live memory forensics, from custom cipher attacks to network protocol fuzzing — the methodology is always the same: enumerate, analyse, exploit, report, and patch.
